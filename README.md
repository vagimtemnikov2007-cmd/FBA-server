# FBA server

Express API для Fresh Block Animations. Supabase хранит карточки, авторов,
заявки и статистику; Cloudflare R2 хранит исходные JSON.

## Cloudflare `fba/jsons`

По умолчанию используются бакет `fba` и префикс объектов `jsons/`:

```text
fba/
  jsons/fall_over.json
  jsons/edge_spin.json
  submissions/<uuid>-pending.json
```

`R2_BUCKET_NAME=fba` и `R2_JSON_PREFIX=jsons`. Если `fba/jsons/` — буквальный
префикс внутри другого бакета, задайте имя того бакета и
`R2_JSON_PREFIX=fba/jsons`.

Переменные окружения перечислены в [.env.example](.env.example). На Render
они задаются в Environment. Для локального запуска на Node 22+:

```bash
npm ci
cp .env.example .env
# Заполните .env значениями своего окружения.
node --env-file=.env server.js
```

В production `PUBLIC_API_URL` должен содержать HTTPS-адрес API,
например `https://fba-server.onrender.com`. Значение по умолчанию берётся
из HTTP-запроса; сервер учитывает HTTPS за обратным прокси.

Ключ R2 должен разрешать чтение и перечисление объектов. Существующие
публикация, одобрение и удаление заявок также используют запись и удаление.
`R2_PUBLIC_URL` сохраняется для совместимости сохранённых URL и публикации.
Браузер получает JSON через API сервера, поэтому публичная выдача бакета
и его CORS не требуются для просмотра и скачивания на сайте.

## API

- `GET /animations` — карточки из существующей таблицы Supabase с
  `animation_url`, `download_url`, `json_status`, `popularity_rank`. `preview_url` остаётся
  в ответе для старых клиентов; новый сайт его не загружает.
- `GET /animations/:id/json` — исходный JSON из R2, `application/json`, ETag
  и условные запросы `If-None-Match`.
- `GET /animations/:id/json?download=1` — тот же файл как вложение.
- `POST /animations/cache/refresh` с заголовком `x-cache-key` — обновление
  каталога. Требуется настроенный `CACHE_REFRESH_KEY`.

Старые Google Drive карточки сопоставляются с файлами в `jsons/` по имени
файла; при нестандартном имени — по `name`/`id` внутри настоящего JSON.
Неоднозначные совпадения остаются недоступными, вместо показа чужой анимации.
ID карточек, авторы и счётчики скачиваний сохраняются. Записи в рабочей БД
автоматически не переписываются; новые адреса формируются в API-ответе.
Существующие ссылки на опубликованные `animations/*.json` поддерживаются.

Популярность определяется существующим полем `animations.download_count`:
больше скачиваний — меньше `popularity_rank` (1 означает первое место).
При равном числе скачиваний выше новая публикация; пустой счётчик равен нулю.
В публичном каталоге `download_count` отсутствует, в интерфейсе числа
скачиваний и места в рейтинге не показываются. Дополнительная миграция БД
не нужна. Рейтинг использует минутный кэш каталога и HTTP-кэш до 30 секунд.

Новые публикации администратора и одобренные заявки попадают в `jsons/`.
Непроверенные заявки остаются в `submissions/`. Поддерживается структурная
проверка JSON formats 1/2 (`transform`) и format 3 (`tracks`).

Каталог объединяет одновременные запросы и обновляется раз в минуту.
Изменение ETag объекта меняет версию `animation_url`, поэтому браузерный
кэш не удерживает прежнюю анимацию после обновления. Публикация/одобрение
сбрасывают кэш сразу. Тела JSON ограничены 2 МБ, серверный кэш — 32 МиБ
или 128 файлов. Сканирование нестандартных имён читает до 512 файлов,
не больше четырёх одновременно; список ограничен 4096 JSON.

## Проверки и развёртывание

```bash
npm test
```

15 проверок покрывают R2-пагинацию, сопоставление мигрированных карточек,
JSON 1/2/3, ограничения файлов, кеширование и инвалидирование, API/ETag/CORS,
скачивание, рейтинг без публичных счётчиков, административные права, публикацию и одобрение. R2 и Supabase
подменяются локальными данными; эти проверки не изменяют рабочие сервисы.

Для общего браузерного прогона из папки FBAsite:

```bash
FBA_SERVER_ROOT=/путь/к/FBA-server npm run test:integration
```

Выкладывайте сервер с `npm ci` и настроенным окружением, затем обновлённый
frontend. Для этих изменений не требуется миграция схемы Supabase.
В текущей локальной копии настоящие переменные окружения отсутствуют:
прямое чтение рабочего R2 здесь не было проверено.
